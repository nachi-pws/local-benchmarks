# LaiLai CLI

A modern TypeScript CLI application built with professional tooling.

## Prerequisites

- **Node.js**: 20.0.0 or higher
- **npm**: 9.0.0 or higher (usually comes with Node.js)

## Setup

1. **Install dependencies**:
   ```bash
   npm install
   ```

## Development

Run the CLI in development mode using tsx (faster TypeScript execution without compilation):

```bash
npm run dev --name "Your Name"
```

For example:
```bash
npm run dev --name "Alice"
```

## Building

Compile TypeScript to JavaScript using tsup:

```bash
npm run build
```

This generates optimized ESM modules in the `dist/` directory.

## Running the Built Application

After building, run the compiled application:

```bash
npm start -- --name "Alice"
```

Or directly:
```bash
node dist/index.js --name "Alice"
```

## Installation as Global CLI

After building, you can install the CLI globally:

```bash
npm install -g .
```

Then use it directly:
```bash
lailai --name "Alice"
```

## Type Checking

Check TypeScript types without generating files:

```bash
npm run type-check
```

```

├── dist/                 # Compiled JavaScript (generated by build)
├── package.json          # Project metadata and dependencies

├── .gitignore            # Git ignore rules

```

## Technology Stack

- **TypeScript**: Static type checking for JavaScript
- **tsx**: Fast TypeScript execution for development
- **tsup**: Simple and fast build tool for TypeScript libraries
- **Commander**: Command-line interface with argument parsing
- **Chalk**: Terminal string styling
- **Zod**: TypeScript-first schema validation
